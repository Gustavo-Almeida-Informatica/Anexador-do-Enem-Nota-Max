# Página Nossa Equipe — ENEM Nota Max

## Publicar no GitHub Pages

1. Baixe e extraia este pacote.
2. Copie `index.html` e a pasta `assets` para a raiz do repositório onde deseja publicar a página.
3. No GitHub, abra **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch (normalmente `main`) e a pasta `/ (root)`, depois salve.
6. Aguarde o GitHub Pages publicar.

Se o repositório já tiver um `index.html` que é a página principal do site, NÃO o substitua sem antes integrar esta página ao projeto. Você pode publicar esta página em uma pasta, por exemplo `equipe/`, mantendo `assets/` dentro dela; nesse caso, o endereço será `https://SEU-USUARIO.github.io/SEU-REPOSITORIO/equipe/`.

As fotos foram associadas conforme a correção do usuário:
- Gustavo Almeida: homem de óculos azuis, camisa social e gravata.
- Max: gato preto com olhos azuis.

Antes de publicar, confira se ambos autorizam a divulgação das fotos e dos perfis.
